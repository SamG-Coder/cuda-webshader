Runtime scope

Pure Bend computations with scalar U32, Nat and F32 entry arguments/results. Recursive calls, captured closures and constructors execute in bounded per-invocation arenas. Independent input rows run in parallel; internal fork/join branches run sequentially. This is a WebShader runtime for checked Bend terms, not upstream BendRT.

The upstream TypeScript checker is included. The Lean-backed verdict and a proof of the translation are not. Nat values are limited to 32 bits; IO, foreign calls, unsafe definitions and package imports are unsupported.
